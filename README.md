# FiJo

Financial awareness before financial advice.

## Overview

FiJo is a Financial Intelligence Platform that transforms personal financial data into actionable financial intelligence.

Instead of simply tracking expenses, FiJo helps users understand their financial health using deterministic financial rules.

## Features

- Financial Dashboard
- Financial Health Score
- Recommendations
- Canonical Financial Catalog
- Knowledge Engine
- Community Insights
