# FiJo Wireframes
Version: 1.0

# General Rules

Every page has one primary objective.

Every page has one primary CTA.

Avoid unnecessary scrolling.

Desktop uses a 12-column layout.

Tablet uses a 6-column layout.

Mobile uses a single-column layout.
