Navigation is always visible.

Maximum navigation depth is 2.

No feature may require more than two navigations from Dashboard.

# Global Rules

Dashboard is for awareness.

Transactions are for recording.

Accounts are for managing assets.

Insights are for understanding behavior.

Community is for anonymous context.

Settings are for configuration.

No page may duplicate the responsibility of another page.

Each page must have exactly one primary responsibility.

Management features never appear on the Dashboard.

Configuration never appears outside Settings.

Operational workflows never appear inside Insights.

Community never exposes personal financial data.

Every feature must strengthen the mission:

Financial Awareness before Financial Advice.
